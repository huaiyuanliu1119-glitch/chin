Merge Sort Interactive Demonstration

This page provides an interactive demonstration of the Merge Sort algorithm with a step-by-step process.

Steps to Follow:

1. Start with an unsorted array.
2. Divide the array into two halves.
3. Recursively sort each half.
4. Merge the sorted halves back together.

Example:

[38, 27, 43, 3, 9, 82, 10]
