氣泡排序

氣泡排序透過重複比較相鄰元素，把較大的值一輪一輪推向尾端。它是最容易理解的排序法之一，也很適合展示排序過程中「比較」與「交換」的概念。

基本原理與操作方式

氣泡排序會從陣列起點開始，逐一比較相鄰兩個元素。如果前者比後者大，就交換位置。這樣一輪跑完後，最大值就會像泡泡浮出水面一樣來到最後面，因此得名。

  1. 從索引 0 開始比較相鄰兩個元素。
  2. 若順序不對就交換。
  3. 一路比較到本輪末端，最大值固定在尾端。
  4. 下一輪縮小比較範圍，直到整個陣列排序完成。

若某一輪完全沒有交換，就代表資料已經排好序，可以提早停止，這也是氣泡排序常見的小優化。

for (let i = 0; i < n - 1; i++) { let swapped = false; for (let j = 0; j < n - i - 1; j++) { if (arr[j] > arr[j + 1]) { [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; swapped = true; } } if (!swapped) break; }

由於每輪都會做大量相鄰比較，當資料量變大時，執行時間會快速上升。這也是為什麼它通常只出現在教學與小型輸入場景。

適用情境

教學示範、資料量很小、需要直觀觀察交換動作時，氣泡排序仍然有價值。

不適用情境

當資料量大到數千或數萬筆時，O(n²) 的成本會非常明顯，應改用合併排序或快速排序。

觀察重點

氣泡排序不是只看最後答案，更重要的是理解每一輪結束後，尾端都有更多元素被固定下來。

範例解析

以 5, 3, 8, 6, 2 為例，第一輪會把 8 推到尾端；第二輪再把 6 推到倒數第二位。這種「每輪確定一個最大值」的節奏，是辨識氣泡排序最直接的方式。
