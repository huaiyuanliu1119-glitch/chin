插入排序

插入排序會維持一段已排序區域，然後把新元素逐一插入正確位置。這個流程很像整理手上的撲克牌，因此直覺且容易理解。

O(n²)

雖然平均和最差情況仍是 O(n²)，但在資料幾乎排好序時，插入排序的實際表現通常明顯優於其他簡單排序法。

  • 穩定排序
  • 原地排序，空間複雜度 O(1)
  • 對小型資料與部分有序資料特別有效
核心操作 取出目前元素，向左比較並插入到已排序區中正確的位置。
穩定性 相同元素通常不會跨越彼此，因此屬於穩定排序。
常見印象 在小規模資料上常有不錯表現，很多高級排序法也會搭配它處理小片段資料。

基本原理與操作方式

插入排序一開始把第一個元素視為已排序，接著每一輪取出下一個元素，向左檢查已排序區，找到適合插入的位置。比它大的元素會整體向右移動，最後再把該元素插入空缺。

  1. 把第一個元素視為已排序區。
  2. 取出下一個元素作為目前待插入值。
  3. 從右往左比較，把較大的元素往右移。
  4. 找到位置後插入，已排序區再擴大一格。

它的節奏不像選擇排序那樣每輪換一次，而是專注在「把現在這個元素塞回正確位置」。

for (let i = 1; i < n; i++) { const current = arr[i]; let j = i - 1; while (j >= 0 && arr[j] > current) { arr[j + 1] = arr[j]; j--; } arr[j + 1] = current; }

穩定性穩定

若資料已接近排序完成，每輪需要移動的元素很少，因此最佳情況只需線性時間。這是它相對於氣泡排序和選擇排序的優勢之一。

適用情境

小型資料集、幾乎排好序的資料，或需要穩定排序且不想額外開空間時，插入排序很實用。

不適用情境

當輸入資料完全亂序且規模很大時，插入排序仍會因大量搬移元素而快速變慢。

觀察重點

每輪新增的是一個「已插好位置」的元素，整個左半段會越來越有序，這是辨識插入排序的關鍵。

範例解析

以 12, 11, 13, 5, 6 為例，第二輪把 11 插到 12 前面，第四輪再把 5 插到最前面。你會看到元素不是一次交換到底，而是透過右移騰出插入空位。
